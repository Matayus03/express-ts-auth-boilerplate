# Express TypeScript Auth Boilerplate

This is an authentication module, developed with Node.js, Express, Typescript and PostgreSQL.

## Technologies used
-Node.js & Express
-TypeScript
-PostgreSQL("pg")
-JSON Web Token (JWT)
-bcrypt

-------------------------------------------------------------------------------------------------------------

## Installation

1. clone the repository:
```bash
    git clone [https://github.com/Matayus03/express-ts-auth-boilerplate.git](https://github.com/Matayus03/express-ts-auth-boilerplate.git)
```

2. install the dependencies:
```bash
    npm install express cors dotenv pg bcrypt jsonwebtoken
```

3. install Typescript types:
```bash
    npm install -D typescript @types/node @types/express @types/cors @types/bcrypt @types/jsonwebtoken @types/pg
```

4. configure environment variables.
    create or modified the .env with your environment variables.

5. configure Database.
    you can execute the schema.sql file or use your own Database.
